# Pilot fitness papers

Papers for building an AI-based physical fitness evaluation program for pilots: classifying aptitude-based physical types from muscular-strength indicators, with decision support.

| File | What it holds |
|---|---|
| [reading-list.md](reading-list.md) | Start here. 328 papers rated for relevance (20 core, 141 rated 4, 167 rated 3) in seven sections, each with a summary and why it is useful. |
| [papers.csv](papers.csv) | The same papers as a table, with DOI, rating and full-text status. |
| [papers.bib](papers.bib) | BibTeX for a reference manager. Entries with a saved PDF have a `file` field. |
| [pdf/](pdf/) | 182 full texts in seven folders that match the reading-list sections. |

PDF file names are `rating_AuthorYear_Title`. A suffix such as `_author-manuscript`, `_preprint` or `_thesis-version` marks a file that is not the published article.

The 146 papers without a PDF are listed at the end of the reading list: 24 are free online but their sites block automated downloads, and 122 need a subscription or a library request.

**Keep this repository private.** The PDFs come from free, legal sources for private study, but many are not licensed for redistribution.
